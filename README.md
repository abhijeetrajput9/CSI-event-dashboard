# CSI-event-dashboard
CSI Event Management Dashboard is a web-based platform designed to help CSI AITR manage and organize college events efficiently. It provides a simple and responsive interface to add, edit, delete, search, and filter events while tracking their status and registration progress.  The dashboard is built using HTML, CSS, JavaScript, and Bootstrap
# CSI Event Management Dashboard

A responsive web dashboard for managing CSI AITR events.

## Features

- Add events
- Edit events
- Delete events
- Search and filter events
- Event status: Upcoming, Ongoing, Completed
- Registration management
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
